# Day 22 – Handle Missing Values

## Internship
VEDA AI & ML Internship

## Objective
Identify, analyze, and handle missing values in a dataset using Python and Pandas.

## Tools Used
- Python
- Pandas
- NumPy
- Matplotlib
- Jupyter Notebook

## Dataset
Titanic dataset.

## Tasks Completed
- Loaded and explored the dataset.
- Identified missing values and calculated missing-value percentages.
- Visualized missing values using a bar chart.
- Filled missing `Age` values using the median.
- Filled missing `Embarked` values using the mode.
- Removed the `Cabin` column because of extensive missing data.
- Compared the original and cleaned datasets.
- Exported the cleaned dataset as a CSV file.

## Files
- `Day_22_Handle_Missing_Values.ipynb` – Jupyter Notebook.
- `titanic_cleaned.csv` – Cleaned dataset.

## Conclusion
This task demonstrated basic data-cleaning techniques using Pandas. Appropriate missing-value treatments were applied, and the cleaned dataset was exported for further analysis and machine-learning applications.
